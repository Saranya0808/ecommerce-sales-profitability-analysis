# E-Commerce Sales and Profitability Analysis

## About the Project
This project uses Exploratory Data Analysis (EDA) to understand retail sales, profitability, discount patterns, and business performance across different regions and customer segments.

## Dataset
- 9,994 records
- 21 original columns
- Order data from 2014 to 2017
- No missing values or exact duplicate rows found during initial data checks

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objectives
- Analyze monthly and yearly sales trends.
- Compare sales and profits across product categories.
- Identify loss-making products and subcategories.
- Examine the relationship between discounts and profit.
- Compare regional and customer segment performance.

## Key Findings
- Total sales: 2,297,200.86
- Total profit: 286,397.02
- Total units sold: 37,873
- Overall profit margin: 12.47%
- Technology had the highest sales among product categories.
- Tables recorded a total loss of 17,725.48.
- The West region generated the highest total sales and profit.
- Discount and profit had a weak negative correlation of -0.219.
